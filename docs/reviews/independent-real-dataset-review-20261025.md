## Important independent methodological findings

1. The original autonomous *candidate score is not scientific adequacy*. The winning 0.607 score did not require any observed JSON examples or causal-LM continuation. It largely reflects metadata and surface feature heuristics rather than the diagnosed deficits.
2. Discovery was **recall-limited**: the 30-candidate cap was reached in the first 3 broad instruction queries, before later targeted queries could execute. Known human-generated and synthetic comparison corpora were absent until independently probed. A complete six-capability search was **not** performed.
3. A `text`-field-based "causal-LM continuation" heuristic misclassifies single OpenAssistant message rows as valid training continuations; `non-repetition` only measures superficial repeated-bigram frequency. These metrics must not substitute for structural task audits.
4. The frozen tokenizer's **1% unknown-token cutoff** rejects several otherwise documented sources in the present raw mixed-language/format preview. This is an explicit policy boundary, not proof the entire source is unusable. English-only source filtering and deterministic normalization can be studied before a new admission attempt without changing the frozen tokenizer.
5. **No full corpus was acquired**. No full-scale deduplication, PII screen, benchmark holdout contamination/semantic leakage audit, rights-clearance, and actual model improvement comparison have occurred. Public card labels are unverified declarations, not definitive underlying rights.
6. The legacy deterministic DatasetSelectionDecision has empty candidate-level `required_approvals` even when the **separate Planner ExperimentProposal** explicitly carries `dataset_selection_approval`. Do not interpret empty candidate-level approvals as authority to acquire. Draft PR #103 separately enforces Planner approval custody and the independent acquisition gate.

## Determination and next scientifically valid move

**Decision: DO NOT APPROVE A DATASET YET.** Preserve the exact immutable model, tokenizer, eval pack, seed and recipe. Add a bounded **capability-targeted** metadata query for structured JSON, short constrained answers, termination and continuation (without retrospectively reclassifying this frozen run); independently audit task structure and contamination against the locked evaluation pack. For the best admissible English candidate, re-run tokenizer compatibility after a documented, reproducible filter using the frozen tokenizer; isolate subset/source licenses, author an explicit mixture hypothesis and a baseline comparison. Only then seek independent, scoped `dataset_selection_approval` and `dataset_acquisition` decisions. No model training, deployment or certification is authorized by this report.
