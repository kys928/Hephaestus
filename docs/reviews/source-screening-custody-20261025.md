## Actual measurements versus missing independent audits

`run_quarantine_source_screening.py` checks the frozen source SHA-256, byte
count, Parquet row count, pinned card license label, original tokenizer bytes,
and source field mapping. All source rows are examined; no sampling ceiling is
silently called a full-source scan. SAF's exact train file is 532,382 bytes /
1,700 rows; WikiText's exact raw train file is 6,357,543 bytes / 36,718 rows.

The scanner measures regex PII candidates in **all string cells**, normalized
exact duplicates in mapped fields, bounded SimHash/Jaccard lexical candidates,
English-heuristic acceptance and unknown-token counts in all accepted rows.
It also compares every mapped source row to six prompts in the existing public
semantic behavior pack and proves contiguous raw-text continuation windows.
No vocabulary changes, threshold relaxation or fabricated EOS tokens occur.

Regex matches require human triage and do not prove PII absence. Near-duplicate
candidate retrieval is not exhaustive; overfull buckets are explicitly counted.
Public-prompt lexical checks do not cover answers or private reference corpora.
No embedding/semantic or human original-text audit is claimed. Source scanning
is **not** the four accepted full scientific audit reports required by
`IndependentDatasetReviewPolicy`.

## Genuine custody cannot be manufactured

The prior scopes have no protected reference IDs. Repository research notes
explicitly say independent original-text custody is not established. Existing
public behavior probes are exposed development material, not a new sealed
holdout. Test fixtures, generated local artifacts, or a new key generated by
this implementer cannot supply independent custody or historical secrecy.

The new `CustodialReferenceManifest` and signature verifier require externally
pinned, distinct training/development/diagnostic/holdout manifests and an
operator-provisioned Ed25519 public key. A signed statement binds all four refs,
the exact separately accepted `custodial-contamination-audit-scope.v1`, validity interval, no training, and execution inside
the custodian environment. Manifests declare original-text availability and
complete exposure inventory, not just case hashes. The verifier checks issuer
identity and byte scope; it cannot prove a custodian's assertions true.

No private text or labels need to enter agent context: the custodian can run
lexical, semantic and frozen-evaluation comparisons privately and return signed
aggregate receipts. This signature verifier is an additive admission tool; it
does not change existing clearance or certification acceptance paths. Production
audit execution still requires those original texts, accepted methods and an
external auditor's judgment.

The new protected-audit scope must explicitly permit protected-reference reads
inside the custodian environment, bind the four exact manifests and named source
file hashes, and authorize lexical/semantic/frozen-evaluation comparisons. The
existing source-only scope forbids such access and is rejected by the verifier;
a signature cannot upgrade it. The provisioning request's original `scope_ref`
identifies source measurements only; the new protected-audit digest is missing
until independently authorized. No protected access is inferred from this request.

The runtime emits a concrete provisioning request with `status` set to
`external_custodian_required`, empty reference refs and no invented public key.
All decision records persist through `state/ScreeningStore`; aggregate reports
are content-addressed. Raw source bytes are confined to a temporary directory
and deleted at exit; they are never uploaded to Actions or committed to git.

## Remaining external input

An actual independent data custodian must provide the four complete frozen
reference identities, public verification key, signed scope-bound permission,
and a private execution route for original-text comparisons. No such identity
is silently appointed here. Dataset approval, training, independent scientific
certification and the 45-operation campaign remain blocked. No paid GPU is used.

The dedicated workflow archives successful aggregate findings under a new
research prerelease `source-screening-triage-v2` when explicitly requested in
its commit marker, with download/recheck of published checksums. Existing
milestone assets are untouched. GitHub hosting is not claimed immutable.
