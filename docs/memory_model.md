# Memory model — stable reference path

Hephaestus uses compact, auditable retrieval derived from persisted run, lineage, decision, evaluation and manifest records. It is **advisory context**, not independent action authority.

See [retrieval memory policy](retrieval_memory_policy.md) for deterministic IDs, source linkage and confidence, and [data/state architecture](architecture/data-and-state.md) for the control-record versus artifact separation. Do not present a generated memory summary as immutable experiment evidence.
