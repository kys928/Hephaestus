# Production dataset acquisition

Production acquisition is a governed step after dataset discovery and selection and before preprocessing. It never searches for a dataset, approves its own plan, preprocesses bytes, or authorizes training.

## Minimal flow

```python
from pathlib import Path

from hephaestus.data import (
    DatasetAcquisitionApproval,
    DatasetAcquisitionCache,
    RemoteAcquisitionLimits,
    RemoteDatasetAcquisitionService,
)
from hephaestus.providers.datasets import HuggingFaceDatasetProvider

provider = HuggingFaceDatasetProvider(enable_network=True)
service = RemoteDatasetAcquisitionService(
    providers={provider.provider_id: provider},
    cache=DatasetAcquisitionCache(Path("/var/cache/hephaestus/datasets")),
)

planning = service.plan(
    candidate=selected_candidate,
    selection=selection_decision,
    limits=RemoteAcquisitionLimits(max_bytes=2_000_000_000, max_files=100),
)
if planning.status != "ready" or planning.plan is None:
    raise RuntimeError([issue.to_dict() for issue in planning.issues])

# Resolve planning.plan.required_approvals through the existing operator policy.
approval = DatasetAcquisitionApproval(
    selection_decision_id=selection_decision.decision_id,
    approved_candidate_ids=(selected_candidate.candidate_id,),
    approval_refs=("approval://operator/example",),
    approved_requirements=planning.plan.required_approvals,
)
result = service.acquire(planning.plan, approval)
if not result.completed:
    raise RuntimeError(result.receipt.to_dict())
```

Use an artifact root outside the Git checkout. Do not commit cache entries, partial files, receipts generated by runs, or downloaded data.

## Gated datasets

Pass only a `SecretReference`; never put a token in a candidate, plan, approval, cache path, or receipt.

```python
from hephaestus.infrastructure import EnvironmentSecretsProvider, SecretReference

reference = SecretReference("environment", "HF_DATASET_TOKEN")
service.secrets_provider = EnvironmentSecretsProvider()
planning = service.plan(
    candidate=selected_candidate,
    selection=selection_decision,
    authentication_reference=reference,
)
result = service.acquire(
    planning.plan,
    approval,
    authentication_reference=reference,
)
```

The runtime reference supplied to `acquire()` must match the reference recorded by `plan()`.

## Offline mode

`service.acquire(plan, approval, offline=True)` performs no provider or transport call. It succeeds only when every planned file has a complete cache entry whose byte size and local SHA-256 verify for the exact provider, dataset ID, immutable revision, file identity, and provider hash.

## Completion rule

Only `receipt.completion_status == "completed"` is usable as an acquisition result. `partial`, `failed`, and `cancelled` receipts are evidence, not datasets. The receipt's cache and artifact references are the only acquired inputs that should cross into preprocessing.

See `docs/integration_notes/feature-production-data-acquisition.md` for provider semantics, receipt fields, failure codes, limitations, and final coordinator wiring.
