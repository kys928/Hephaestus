## V2 fourth engineering checkpoint

PostgreSQL is the leading research persistence candidate. The opt-in composition binding uses the same blackboard admission, replay, checkpoint and restore logic as the host-local rehearsal. PostgreSQL locks each investigation's controller epoch inside the contribution transaction, checks the pinned epoch and appends before acknowledging. A controller uses a compare-and-swap update to advance ownership. Reconciliation reads the accepted ID after an uncertain response. Model and worker processes do not receive write credentials.
