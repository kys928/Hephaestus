# Control spine — stable reference path

The mandatory eight phases are **Judge entry → Planner → Data acquisition and audit → Data preprocessor → Training engineer → Runtime monitor → Evaluator → Judge exit**. Control orchestration is not a substitute for individual specialized roles or deterministic policy.

See the maintained [phase-by-phase explanation](architecture/control-and-governance.md), [architecture map](architecture/README.md) and the authoritative [project mission](../PROJECT_MISSION.md). R10's 45 native operations are a distinct experiment-specific metric, **not** 45 global control phases.
